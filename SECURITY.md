# Security Policy

This repository is a pre-production foundation. Do not use it to custody assets,
issue UFT, make credit decisions, or submit mainnet transactions.

Report suspected vulnerabilities privately to the repository security owner.
Do not include credentials, personal data, exploit payloads against third-party
systems, or real account information in a report.

Public deployment remains blocked until the independent audit, formal
verification, economic simulation, key-management, recovery, and operational
gates in the governing specifications are satisfied.
