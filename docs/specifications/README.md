# Specification Set

The canonical v0.1 specification set contains twelve documents. The Constitution
is the highest authority; every other document is subordinate.

```text
Unified Constitution
├── Unified Domain Model
│   ├── Universal Loan Model and State Machines
│   │   ├── Financial Accounting Specification
│   │   └── Smart Contract Interface and Protocol API
│   └── On-Chain/Off-Chain Data Architecture
├── UFT Tokenomics and Economic Security
├── Threat Model and Adversarial Security
│   └── Protocol Invariants and Formal Verification
├── System Architecture and Deployment Topology
├── Repository Architecture and Engineering Constitution
└── Implementation Master Plan
```

`registry.yaml` is generated by `tools/build_spec_registry.py`. It records the
canonical path, content hash, authority role, dependencies, and implementation
baseline status. A specification content change must regenerate the registry and
pass review before a new baseline tag is created.
