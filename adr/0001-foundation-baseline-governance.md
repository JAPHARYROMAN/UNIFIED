# ADR 0001: Foundation Baseline Governance

- **Status:** Accepted
- **Date:** 2026-07-24
- **Owner:** Program Authority

## Decision

The twelve v0.1 specifications are approved as a foundation implementation
baseline and recorded by content hash. The annotated tag
`spec-baseline-v0.1.0` identifies the baseline. This is not production
ratification.

Changes after the tag require a work-item identifier, impact review, regenerated
registry, and a new baseline version. Constitutional conflicts are rejected;
safety ambiguity uses the more restrictive interpretation until an ADR resolves
it.
